# Módulo: Catálogo

Este módulo está reservado para la futura implementación del catálogo de productos de M&M Medical.

## Archivos previstos
- `catalogo.js` — Vistas y lógica del módulo
- `catalogo.css` — Estilos específicos (opcional)

## Cómo integrar
Cuando esté listo, agregar en `index.html`:
```html
<script src="modules/catalogo/catalogo.js?v=..."></script>
```
