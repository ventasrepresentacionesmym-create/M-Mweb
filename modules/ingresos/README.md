# Módulo: Ingresos

Este módulo está reservado para la futura implementación del registro de ingresos de M&M Medical.

## Archivos previstos
- `ingresos.js` — Vistas y lógica del módulo
- `ingresos.css` — Estilos específicos (opcional)

## Cómo integrar
Cuando esté listo, agregar en `index.html`:
```html
<script src="modules/ingresos/ingresos.js?v=..."></script>
```
